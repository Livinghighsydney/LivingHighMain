# WordPress export — migration source of truth

Structured content + SEO extracted from the legacy WordPress dump. This is what
the new Next.js + FastAPI stack rebuilds against. Generated by
[`backend/scripts/wp_extract.py`](../../backend/scripts/wp_extract.py) — it does
**not** migrate the raw MySQL schema (see CLAUDE.md "Migration approach").

## Regenerate

```bash
cd backend
python scripts/wp_extract.py \
  --dump ../old_db/livinghighcom1_wp_q2vy9.sql.gz \
  --out ../docs/wp-export --types page,post
```

(The dump itself is kept off-repo — see `.gitignore` / cold backup.)

## Files

| File | Committed | What |
| --- | --- | --- |
| `url-map.json` | ✅ | **The master artifact.** One entry per live URL: full path (trailing slash), language (`en`/`es`/`zh`), `translation_group`, and Yoast SEO (title/description/canonical/OG). Drives URL preservation + `<head>` metadata. |
| `taxonomy.json` | ✅ | Terms, taxonomies, and post→term relationships. |
| `summary.json` | ✅ | Counts + distributions from the last run. |
| `posts.json` | ❌ (gitignored) | Full page/post bodies (Elementor-heavy, ~3.4 MB). Regenerable; becomes the DB seed later. |
| `yoast.json` | ❌ (gitignored) | All 970 raw Yoast rows (posts + archives + terms). Regenerable; `url-map.json` already distills the useful part. |

## What the extraction established

- **169 live URLs**: 120 `en` + 25 `/es/` + 24 `/zh/` (trilingual via independent
  page trees — no translation plugin). 150 carry explicit Yoast SEO; the 19 without
  are functional/system pages (checkout, my-account, membership, thank-you,
  password-reset) — most don't exist in the new stack; write fresh meta for the
  few real ones (contact, blog, testimonials).
- **Listings are WordPress `page`s, not WooCommerce products** — all 755 products
  are `draft`/`importing`, never published. No booking/checkout content to carry.
- **`translation_group`** aligns EN/es/zh variants of a page (language-prefix
  stripped from the path) → maps onto the `translation_group` field on the
  content models.
- The suspicious `wa.me/+375259112693` (Belarus) number is **not** in any
  published page/post body — it lives in a widget/plugin option, so it will not
  be carried into migrated content.
